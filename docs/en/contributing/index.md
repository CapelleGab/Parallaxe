# Contributing

Thanks for your interest in Parallaxe! At this early stage, the most valuable contributions are **feedback, bug reports and small, focused pull requests**. English and French are both welcome.

The full guide lives in [`CONTRIBUTING.md`](https://github.com/CapelleGab/Parallaxe/blob/main/CONTRIBUTING.md). In short:

1. Read the [ground rules](https://github.com/CapelleGab/Parallaxe/blob/main/CONTRIBUTING.md#ground-rules) — originals are read-only, no account, no telemetry, no invented values.
2. Open an issue before starting a feature outside the [roadmap](../project/roadmap.md).
3. [Set up](setup.md) the project.
4. Follow the [conventions](conventions.md).
5. Update the [documentation](documentation.md) in English and, when you can, in French.

Security issues are reported privately — see the [security policy](https://github.com/CapelleGab/Parallaxe/blob/main/SECURITY.md).
