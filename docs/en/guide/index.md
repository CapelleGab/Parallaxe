# Guide

Parallaxe is still in design: there is nothing to install yet. This guide describes the concepts and the behavior the app is being built around, so that early testers and contributors share the same vocabulary.

- [Concepts](concepts.md) — libraries, roots, assets, tags, collections and states.
- [Supported formats](formats.md) — what 0.1.0 will catalog, preview and inspect.
- [Privacy](privacy.md) — what Parallaxe does and does not do with your files.
