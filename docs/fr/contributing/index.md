# Contribuer

Merci de ton intérêt pour Parallaxe ! À ce stade, les contributions les plus utiles sont **les retours, les rapports de bugs et les petites pull requests ciblées**. Le français et l'anglais sont tous deux bienvenus.

Le guide complet est dans [`CONTRIBUTING.md`](https://github.com/CapelleGab/Parallaxe/blob/main/CONTRIBUTING.md) (en anglais). En résumé :

1. Lis les [règles de base](https://github.com/CapelleGab/Parallaxe/blob/main/CONTRIBUTING.md#ground-rules) — originaux en lecture seule, pas de compte, pas de télémétrie, pas de valeur inventée.
2. Ouvre une issue avant de commencer une fonction hors de la [roadmap](../project/roadmap.md).
3. [Installe](setup.md) le projet.
4. Suis les [conventions](conventions.md).
5. Mets à jour la [documentation](documentation.md) en anglais et, si tu peux, en français.

Les problèmes de sécurité se signalent en privé — voir la [politique de sécurité](https://github.com/CapelleGab/Parallaxe/blob/main/SECURITY.md).
